# Connection Circles

A graphic organiser from The Shape of Change (Rob Quaden and Alan Ticotsky, 2004). Use it to find the feedback loops in a story or situation, before you draw a causal loop diagram.

## Structure

| Part | Rule |
|---|---|
| Element | A noun or noun phrase that can increase or decrease: "Books Sold", not "Books". 5 to 10 at most |
| Arrow | From a cause to its direct effect |
| Loop | A path of arrows that returns to its start. The loops are the result |
| Polarity | "+": cause and effect change in the same direction. "-": in opposite directions. Not in the original rules |
| Loop type | Even number of "-" arrows (zero included): reinforcing (R). Odd number: balancing (B) |

## Steps

1. Write the 5 to 10 most important elements around a circle
2. For each element, draw an arrow to each element that it directly increases or decreases
3. Follow the arrows. Write each path that returns to its start as a chain: "A -> B -> C -> A"
4. Redraw each loop separately and tell its story
5. Mark each arrow "+" or "-". Label each loop R or B. The labelled loops make a causal loop diagram

## Checks

- Arrows counted, loops not traced: arrow counts are not the result. List each closed path
- Indirect or correlated link: keep an arrow only if you can say how it works
- Loop type by count only: also follow an increase around the loop. It returns as an increase (R) or a decrease (B)
- Element with no arrow in or out: look for a missing element

## Wrong Tool When

- The user needs numbers or proof of causation: the circle is qualitative and shows beliefs
- Nothing increases or decreases: the circle has no elements
